### ✅ 1. Fork This Repository  
Click the **Fork** button (top‑right of GitHub).  
This creates **your own copy** where you will push your solution.

```

```

### ✅ 2. Clone Your Fork
```bash

```

### ✅ 3. Open `train.py`  
Fill in:
- data loading  
- preprocessing  
- model training  
- evaluation  

### ✅ 4. Save Your Evaluation Score  
Your script MUST save results to `metrics.json`:

```json

}
```

### ✅ 5. Push to Your Fork  
```bash
git add .
git commit -m "done"
git push
```

Your push will be **automatically validated** by the system.
